# Figure request - rounding off and truncation errors
 
## Objective
Show how a decimal number is approximated by rounding off and truncation to a specific number of decimal points / places.
A point p represents the working value on a horizontal number line (0-4). As students drag p, the rounded value and trancated value updates instantly so they can observe how the how each approximation is formed.
The exploration should help students discover that rounding chooses the nearest representable value, whereas truncation simply removes unwanted digits.
Students should also observe how the approximation errors change as the working value changes. 
Identify when the two methods produce the same or different results.
 
Topic: Approximations and Errors (Rounding off and Truncation of errors)
 
## What moves, what stays fixed
- Draggable: Point P, representing the working decimal number (To 1 d.p).
- Derived: Rounded value R of P to 1 decimal places.
- Derived: Truncated value T of P to 1 decimal places.
- Derived: Rounding error = |Working value − Rounded value|.
- Derived: Truncation error = |Working value − Truncated value|.

All derived quantities update automatically whenever P changes.
## Readouts
- Working value
- Rounded value
- Truncated value
- Rounding error
- Truncation error

so students can see when the two errors may differ or be the same.
## Visualizations
- Display a horizontal number line with appropriate tick marks.
- Show the working value P as a movable point.
- Show the rounded value R as a fixed coloured point.
- Show the truncated value T as another fixed coloured point.
- Draw line segments from P to R and from P to T so that the sizes of the rounding and truncation errors can be compared visually.

## Naming
- Filename: rounding-truncation-errors
- Board ID: jsx-rounding-truncation-errors
- Axes + grid: yes

# Figure request - addition and subtraction of errors
 
## Objective
Show how errors propagate when two measured quantities are added and subtracted. 
Two measured quantities, Length (L) and Width (W), each have a working value together with their maximum and minimum possible values resulting from measurement uncertainty.

As students drag the working measurements, the maximum and minimum limits update instantly. The exploration automatically generates every possible combination of the measurements for both addition and subtraction so that students can investigate how the largest and smallest results are obtained.

The exploration should help students discover that:

- the maximum sum is obtained by adding the maximum values;
- the minimum sum is obtained by adding the minimum values;
- the maximum difference is obtained by subtracting the minimum value of the second quantity from the maximum value of the first quantity;
- the minimum difference is obtained by subtracting the maximum value of the second quantity from the minimum value of the first quantity;
- the absolute, relative and percentage errors depend on the maximum and minimum possible results.

Students should first predict, then reveal, and finally verify the error propagation rules by changing the measurements.
 
Topic: Approximations and Errors (Addition and subtraction of errors)

- Working sum.

For subtraction:

All nine possible differences.
- Maximum difference.
- Minimum difference.
- Working difference.

For both operations:
- Absolute error.
- Relative error.
- Percentage error.

All derived quantities update automatically whenever L or W changes.
