# Archived JSXGraph scripts

These scripts are not used by any `<interactive>` in `source/`. They were moved
here (November 2026) to keep `assets/jsxgraph/` easy to navigate. To bring one
back, move it to its old folder and embed it with
`<interactive ... source="jsxgraph/<name>.js">`.

`relation-vs-function.js` here is the old copy from `functions/`; the version
in use is `assets/jsxgraph/relation-vs-function.js`.
